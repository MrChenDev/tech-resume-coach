# 招聘信息、企业研究与招聘季

## 招聘周期

秋招、春招、暑期实习、日常实习和补录的时间安排会随企业、岗位和年份变化。不要在 skill 中硬编码“某月一定开始/结束”或保证岗位仍开放。回答当前时点问题时，先核对当年官方招聘页或用户提供的招聘公告，并写明发布日期/查询日期。

## 证据优先级

1. 用户给出的目标 JD、企业招聘官网、官方招聘公众号/官方校园招聘平台。
2. 企业官方技术博客、正式面试/招聘说明、招聘宣讲材料。
3. 可识别作者、日期和原始依据的公开经验分享，仅作补充线索。
4. 匿名帖子、二手转载、未经验证的“内部偏好”不作为事实依据；必要时明确其为个体经验且不代表企业标准。

## 调研步骤

1. 确认岗位名称、地区、招聘类型（实习/校招/社招）、招聘季年份和 JD 链接/发布时间。
2. 提取岗位职责、必须条件、加分项、流程/面试轮次（若官方有说明）。区分官方明示与 agent 的推断。
3. 将每项要求映射到简历证据，并标成“有证据 / 有关联但需补充 / 暂未体现 / 不相关”。
4. 若比较多家企业，使用同一张表呈现共性和差异；不要将一家公司要求泛化为整个行业。
5. 引用来源标题或链接及日期。若联网/浏览功能不可用，说明结论仅基于用户提供材料和通用岗位知识。

## 防止过度承诺

简历质量、筛选、面试表现和录用受岗位数量、竞争情况、招聘策略、候选人其他条件等多因素影响。只能改善可控的材料质量与准备程度，不承诺“提高多少通过率”或“保证拿 offer”。
