# 合成验收案例

以下案例均为虚构，不代表真实候选人或企业，不应用于招聘决策。用于检查 skill 是否按证据评价学生经历、识别岗位差距、保留事实并避免编造数字。

| 案例 | 方向 | 重点检查 |
|---|---|---|
| `backend-intern` | 后端实习 | 课程项目/团队贡献区分、测试证据、不得虚构性能数据 |
| `embedded-intern` | 嵌入式软件实习 | MCU/外设证据、RTOS 缺口识别、不得夸大为量产经验 |
| `data-engineering-intern` | 数据工程实习 | 小规模本地数据管道与大数据平台要求区分 |

把案例中的 `resume.md` 和 `job-description.md` 提交给 skill，要求给诊断分、证据映射、优先修改项和一条改写示例，再按 `expected-checks.md` 人工核对。分数允许合理波动，事实边界和关键缺口必须满足。
